# CRS scoring and scenario preparation release contract

## Scope and release status

This package completes local deterministic review and evidence contracts. It does
not activate numerical CRS, amend existing entitlements, or make an immigration
eligibility/invitation decision. The public assessment total and every factor's
points remain null. The retained heuristic calculators are not used.

The pre-November candidate applies from 2025-03-25 through 2026-11-02. Its existing
literal source vectors and the new hand-derived work examples are local accuracy
evidence, not a signed independent human release. November 3 selects a separate
candidate marked UNDER_REVIEW, with no guessed overall cap. The NOC occupation
list has an immutable version and digest; personal salary is not a classification.
Dates, fixtures and operator environment variables cannot authorize either release.

## Authoritative evidence and inputs

`RankingFacts` is strict and rejects unknown fields, coercion and invalid ranges.
Unknown differs from explicit zero/no. Four language skills must be present for
each claimed language. Owned selected language assessments and their current
mapping/expiry replace any client-declared benchmarks during public review.
Legacy aggregate profile language values cannot become accepted test evidence.
Profile age/recognized education may fill missing declarations without modifying
Profile; explicit what-if inputs remain detached preparation.

Work periods use the application's finite country-code vocabulary, a known
five-digit NOC, paid/duties declarations and ISO calendar dates with an exclusive
end. Canadian periods additionally require explicit authorization, student and
self-employment answers. Unsupported exceptions and unknown qualifications
withhold the review candidate; genuine nonqualifying periods contribute zero.
Future periods and contrary aggregate-year declarations cannot be silently fixed.

The bounded endpoint sweep clips periods to the ten-year CRS window and caps
concurrent credit at 30 hours per week using exact fractions. Complete-year credit
requires hours, equivalent duration and the applicable calendar anniversary.
Concurrent Canadian/foreign periods are review-required, not optimistically
classified. Canadian work evidence is not automatically CEC eligibility evidence;
program-specific windows and exceptional public policies require separate review.

## Deterministic calculation and independent acceptance

The local candidate returns named factors, section totals, explicit cap adjustments,
table digest, evidence provenance and its rule version. Transferability combines
are capped at 50 and the section at 100; additional points at 600 under the old
rules. The full old-rule total is capped by its reconciled 1200-point structure.
No old job-offer bonus is resurrected. Future LMI fixture arithmetic selects the
better work/offer alternative and never adds both or adds work length twice.
Complete amended instructions, spouse/factor/nomination interactions, occupation
list lock, exceptional qualification and the revised total cap remain November
release gates. A source publication date is not a legal effective date.

Expected test results are literal independently derived arithmetic, not values
generated by calling the same implementation. Every age/language/education/work
threshold, spouse mode, section cap, immediately-below boundary and unsupported
case must pass before a separate independent numerical release decision.

## Saved preparation and scenario ownership

The existing Free facts GET/PUT remains available with its revision contract.
New scenarios are bounded to ten distinct identifiers and 80-character titles.
The explicit persistence service requires a currently entitled individual Pro,
owns the case, locks the owner and checks a separate scenario revision. It stores
facts/source versions and language-evidence references, never a numerical score.

Scenarios live in `crs_preparation.scenario_preparation`, a separate nested
namespace inside the existing server-protected Forms key. This avoids adding an
unprotected root key which legacy Forms replacement could erase. Free fact saves
preserve scenario revisions, and scenario saves preserve facts and all Forms keys.
Reads do not create workspace records. Atomic owner-lock/CAS tests run on isolated
PostgreSQL 16/18; a stale writer receives 409 without replacing a winning save.

Both public scenario operations remain behind the hard false
`SCENARIO_PREPARATION_RELEASED` gate. This is not an environment-variable switch.
Local service tests prove implementation behavior without releasing paid access.
No existing user plans, entitlement checks or billing implementation are changed.
